## 📂 Projects

This repository includes the following Data Science projects:

### 1. 📈 Mortality Rate Prediction

* An exploratory and predictive data science project.
* Analyzes relevant factors associated with mortality rates.
* Applies data preprocessing and machine learning techniques to build predictive models.
* Focuses on understanding patterns and generating meaningful insights from data.

### 2. 📩 Spam SMS Classification

* A machine learning project that classifies SMS messages as Spam or Ham (Not Spam).
* Uses text preprocessing and Natural Language Processing techniques.
* Applies machine learning algorithms for text classification.
* Evaluates model performance to understand classification accuracy.

### 3. 💳 Credit Data Exploratory Data Analysis (EDA)

* Explores credit-related datasets to identify patterns and trends.
* Performs data cleaning, preprocessing, and statistical analysis.
* Uses data visualization to understand relationships between different variables.
* Extracts meaningful insights to support data-driven understanding.
